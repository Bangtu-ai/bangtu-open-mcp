客户端配置

将 apiKey 替换为你的专属调用凭证。(如有需要生成专属 apiKey 请联系客服) 
{
  "mcpServers": {
    "bangtu-api": {
      "url": "__BANGTU_MCP_URL__",
      "apiKey": "请填入您的apiKey"
    }
  }
}

每次工具调用均通过 apiKey 识别客户并完成服务计量。

帮图 MCP 工具

围绕 DWG 图纸解析任务设计的工具集。智能体可以按“创建任务、等待完成、读取结果”的流程调用，无需自行拼接上游接口路径。

重要提示
  • 图纸仅支持 DWG 格式文件。
  • 天正（TArch）图纸需先导出为 T3 版本后再上传。
  • 图纸中存在外部参照（Xref）时，需先绑定参照后再上传，避免图元缺失。
